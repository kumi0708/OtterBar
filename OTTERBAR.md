# OtterBar fork

This repository turns RunCat Neo into **OtterBar**, a menu-bar otter that spins on a rope, sleeps while you are away, and reacts to builds and AI agents. Usage and integrations are described in [README.md](README.md).

## What changed

- **New built-in runner `otter`** (now the default). Its frames for every behavior live in `Media.xcassets/Runners/Otter`, generated by `otterbar/tools/render_otter.swift` (see "Artwork" below).
- **`PetState` / `PetEvent`** (`DataSource/Entities/Pet`) — the behaviors, their frame counts, playback (loop or once, CPU-linked or fixed speed), priority rank, and the Darwin notification names that map to events.
- **`PetStateMachine`** (`Model/Services`) — pure state logic: resting state from flags (building > agent working > sleeping > play), one-shot reactions that cannot be interrupted by lower-ranked events, duplicate suppression, and generation-checked completion.
- **`PetService`** (`Model/Services`) — an actor that polls idle time every 2 s, listens for `com.otterbar.*` Darwin notifications, schedules random acts and long-session reminders, and publishes `AppState.petStates`.
- **`RunnerBar` / `RunnerLayer`** — when the otter is selected, swap frame sets per state; one-shot animations play once and hold the last frame; fixed-speed states override the CPU-linked speed and restore it afterwards.
- **`PetSettings`** — a section in Runner settings showing the current state, toggles for idle/events/random acts, idle minutes, and buttons that post test events through the real notification path.
- **New dependency clients**: `IdleTimeClient` (`CGEventSource.secondsSinceLastEventType`) and `DarwinNotificationClient` (`notify_register_dispatch` / `notify_post`).
- **App identity**: product `OtterBar`, bundle ID `local.otterbar.OtterBar`, display name OtterBar, an otter app icon, so it coexists with the App Store RunCat Neo.
- **Removed**: the donation tab (StoreKit products and subscription group of the original author), and the RunCat Neo website under `docs/`.

## Build

```bash
cd LocalPackage
xcodebuild -scheme LocalPackage-Package -destination 'platform=macOS,arch=arm64' \
    -skipPackagePluginValidation -skipMacroValidation test
```

The app is built ad-hoc signed (universal) by `otterbar/build-app.sh`. To build from Xcode, set your own team under Signing & Capabilities.

## Artwork

Every frame is drawn procedurally by `otterbar/tools/render_otter.swift`, which `build-app.sh` runs before each build. It writes the asset catalog entries plus previews (`otterbar/frames/preview/<animation>.png|gif`).

- The spin (`play`, `build`) is a 3D rig (`yawRig`): the otter bites the rope and swings around it like a conical pendulum; `cone` is the body's angle from vertical, `lag` the tail delay, `ropeSwing` how far the rope swings out, and `cameraElevation` how much we look down on the circle.
- The other behaviors are 2D poses (`Pose`) built from a spine angle function, paws, eyes, and extras (Zs, sparkles, pebbles).
- `bodyLength` / `radius(at:)` define the body shape, `displayScale` the size within the 36 px tall canvas.
- `swift otterbar/tools/render_otter.swift --icon <png>` regenerates the app icon glyph (`RunCatNeo/AppIcon.icon/Assets/otter.png`).

A character set is a folder of 36 px tall PNGs named `<runner id>-<animation>-frame-<N>` (`<runner id>-frame-<N>` for `play`); frame counts and playback speeds come from `PetState`.
